# Sari-Sari Store

A Java desktop application for managing products, inventory, sales, and reports.

## Project structure

```text
SariSariStore/
├── Main.java
├── model/
│   └── Product.java
├── service/
│   ├── InventoryService.java
│   ├── SalesService.java
│   └── ReportService.java
├── gui/
│   ├── MainFrame.java
│   ├── ProductPanel.java
│   └── SalesDialog.java
└── util/
    └── MoneyFormatter.java [optional]
```
